# AllZone.uz - Uzbekistan Business Directory

A modern, full-featured business directory platform for Uzbekistan built with Next.js 15.5.6, TypeScript, and Untitled UI components.

## 🚀 Features

- **Modern UI** - Built with Untitled UI + Tailwind CSS + Heroicons
- **TypeScript** - Full type safety
- **Responsive Design** - Mobile-first approach
- **SEO Optimized** - Meta tags, sitemap, structured data
- **Fast** - Next.js 15 with App Router
- **Scalable** - MongoDB ready architecture

## 🛠️ Tech Stack

- **Framework**: Next.js 15.5.6
- **Language**: TypeScript
- **UI**: Untitled UI + Tailwind CSS
- **Icons**: Heroicons
- **Auth**: NextAuth.js (ready)
- **Database**: MongoDB + Mongoose (ready)

## 🚦 Quick Start

```bash
# Clone repository
git clone https://github.com/SanjarAbduraimov/allzone.uz-frontend.git
cd allzone.uz-frontend

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
